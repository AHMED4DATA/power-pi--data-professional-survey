# power-pi--data-professional-survey
This project analyzes survey data from professionals in the data field, offering insights into average salaries, preferred programming languages, participant distribution by country, and the challenges of entering the field. It includes various visualizations to help users understand key trends.
# Data Professional Survey Breakdown

## **Overview**
This project provides an in-depth analysis of a survey conducted among 630 data professionals, featuring:
- **Average salaries by job role**
- **Most preferred programming languages**
- **Geographical distribution of participants**
- **Challenges of entering the field by country**
- **Salary comparisons based on gender**

## **Technologies Used**
- **Power BI** for data visualization and dashboard design
- **SQL** for data retrieval and manipulation
- **Excel** for additional analysis and organization

## **Usage**
This project helps users understand professional trends in data-related fields and analyze salary distributions based on various factors. It sheds light on the challenges of entering the industry and provides valuable insights for decision-makers.

## **Installation**
To explore the project, follow these steps:
1. **Download the file** and open it in Power BI.
2. **Analyze the data** and apply modifications as needed.
